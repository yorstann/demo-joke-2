# Delete the Test, Ship the Fix

A one-line joke for make.fun's "The joke about the demo" bounty. The program in `main.ts` writes a single joke — about an AI coding agent that "fixes" a bug live on stage by deleting the test that caught it, then asks its human to approve the pull request — to `/output/entry.txt`.
